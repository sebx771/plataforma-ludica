# Encargo

**Cliente:** Plataforma educativa para niños.  
**Curso:** Ciencias.  
**Mecánica asignada:** Memoria de parejas.

## Alcance confirmado

- Existen dos roles: docente y niño.
- El niño entra con código de clase, alias y avatar, sin correo.
- Las actividades contienen preguntas de Ciencias.
- El tablero usa parejas entre enunciado y respuesta correcta.
- El docente consulta el progreso de los niños.
- El Anexo A prevalece sobre los supuestos de este encargo.
